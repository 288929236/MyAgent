# 项目技术框架说明

## 一、整体架构

```
┌─────────────────┐     HTTP/REST      ┌─────────────────┐
│   前端 (Electron) │ ◄──────────────► │   后端 (FastAPI)  │
│   React + TS     │                   │   Python         │
└─────────────────┘                   └─────────────────┘
                                                │
                                                ▼
                                        ┌─────────────────┐
                                        │  DeepSeek API   │
                                        │  (大模型)        │
                                        └─────────────────┘
```

---

## 二、前端技术栈

### 核心框架
| 技术 | 作用 |
|------|------|
| **Electron** | 桌面应用框架，把网页打包成 Windows/Mac 应用 |
| **React** | UI 框架，负责页面渲染和交互 |
| **TypeScript** | 编程语言，JavaScript 的超集，带类型检查 |

### 构建工具
| 技术 | 作用 |
|------|------|
| **Vite** | 前端构建工具，开发时热更新，打包时压缩代码 |
| **electron-builder** | 把 Electron 应用打包成 exe 安装包 |

### 常用库
| 技术 | 作用 |
|------|------|
| **react-markdown** | 把 AI 返回的 Markdown 格式渲染成好看的页面 |

---

## 三、后端技术栈

### Web 框架
| 技术 | 作用 |
|------|------|
| **Python** | 后端编程语言 |
| **FastAPI** | Web API 框架，提供接口给前端调用 |
| **Uvicorn** | ASGI 服务器，运行 FastAPI 应用 |

### AI Agent 框架
| 技术 | 作用 |
|------|------|
| **LangChain** | LLM 应用开发框架，封装了模型调用、工具调用等 |
| **LangGraph** | Agent 状态机框架，管理对话流程和记忆 |
| **DeepSeek** | 大模型，提供 AI 能力 |

### 数据存储
| 技术 | 作用 |
|------|------|
| **SQLite** | 轻量级数据库，存对话历史、用户信息 |
| **python-dotenv** | 加载 .env 环境变量文件 |

### 打包工具
| 技术 | 作用 |
|------|------|
| **PyInstaller** | 把 Python 后端打包成 exe 可执行文件 |

---

## 四、CLI 工具

| 技术 | 作用 |
|------|------|
| **Rich** | 终端美化，渲染 Markdown 格式的输出 |
| **LangChain / LangGraph** | 和后端共用的 Agent 逻辑 |

---

## 五、项目目录结构

```
MyAgent/
├── backend/          # 后端（FastAPI + Agent）
│   ├── api.py        # Web 接口
│   ├── agent.py      # Agent 核心
│   ├── tools/        # 工具集
│   └── requirements.txt
│
├── cli/              # CLI 命令行工具
│   ├── main1.py      # 基础对话测试
│   ├── main2.py      # 文件夹操作 Agent
│   └── tools/        # 工具集
│
├── frontend/         # 前端（Electron + React）
│   ├── src/
│   ├── package.json
│   └── electron-builder.yml
│
├── data/             # 数据存储（db 文件）
├── .snapshots/       # 文件修改快照
└── docs/             # 项目文档
```
