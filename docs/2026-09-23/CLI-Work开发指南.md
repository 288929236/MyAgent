# CLI-Work 开发指南

## 整体流程

```
用户启动 → 输入文件夹路径 → 验证目录 → 初始化 Agent → 进入对话循环
                                    ↓
用户输入需求 → Agent 思考 → 调用工具 → 安全检查 → 执行操作 → 记录修改 → 保存快照 → 返回结果
```

---

## 详细步骤

### 1. 导入指定文件夹

```
用户: "接管 ./my-docs 文件夹"
```

- 验证路径是否存在
- 验证是否是目录
- 设置 `work_dir = 用户输入的路径`
- 打印当前目录下的文件列表

---

### 2. 四个自定义工具（md 文档增删改查）

| 工具名 | 功能 | 输入 | 输出 |
|--------|------|------|------|
| `read_md` | 读取 md 文档 | 文件名 | 文件内容 |
| `create_md` | 新建 md 文档 | 文件名、内容 | 成功/失败 |
| `edit_md` | 修改 md 文档 | 文件名、要替换的内容、新内容 | 成功/失败 |
| `delete_md` | 删除 md 文档 | 文件名 | 成功/失败 |

**安全限制：**
- 只能操作 `.md` 文件
- 不能用 `../` 访问上级目录
- 只能在 `work_dir` 内操作

---

### 3. 安全性验证

**执行工具前必须检查：**
- ✅ 文件后缀是 `.md`
- ✅ 路径在 `work_dir` 内
- ✅ 删除/修改前先备份
- ✅ 敏感操作（删除）可以加确认提示

---

### 4. Agent 工作循环

```
用户: "帮我新建一个 README.md，写项目介绍"
    ↓
Agent 思考: 需要调用 create_md 工具
    ↓
调用 create_md(filename="README.md", content="...")
    ↓
安全检查 → 通过
    ↓
执行工具 → 写入文件
    ↓
记录修改日志 → 保存快照
    ↓
返回结果: "已创建 README.md"
```

---

### 5. 记录修改 + 快照保存

**每次修改前：**
1. 先把原文件内容存到快照目录
2. 记录修改日志（谁、什么时候、改了什么）
3. 格式：`snapshots/2026-09-23_14-30-00_README.md`

**好处：**
- 改坏了可以回滚
- 可以看历史版本

---

## 总结

```
1. 初始化：用户输入文件夹路径 → 验证 → 设置 work_dir
2. 定义工具：4 个 md 操作工具（带安全限制）
3. 对话循环：
   用户输入 → Agent 思考 → 选工具 → 安全检查 → 执行 → 记录修改 → 保存快照 → 返回结果
4. 退出时：打印修改记录总结
```
