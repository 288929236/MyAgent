# MyAgent 项目搭建指南

## 目录结构

```
MyAgent/
├── backend/           # 后端（FastAPI + LangGraph）
├── frontend/          # 前端（Electron + React + TypeScript）
├── data/              # 数据目录（开发环境）
├── .venv/             # Python 虚拟环境
├── .env               # API Key 配置
├── .gitignore
├── requirements.txt   # Python 依赖
└── docs/              # 文档
```

---

## 一、环境准备

### 1. 安装 Python
- 下载 Python 3.10+：https://www.python.org/downloads/
- 安装时勾选 "Add Python to PATH"

### 2. 安装 Node.js
- 下载 Node.js 18+：https://nodejs.org/
- 安装默认选项即可

---

## 二、创建 Python 虚拟环境

### 1. 创建虚拟环境
```bash
# 在项目根目录 MyAgent/ 下运行
python -m venv .venv
```

### 2. 激活虚拟环境
**Windows PowerShell：**
```bash
.venv\Scripts\Activate.ps1
```

**如果报错（执行策略限制）：**
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 3. 安装后端依赖
```bash
# 激活虚拟环境后
pip install -r backend/requirements.txt
```

## 四、前端项目脚手架

### 1. 创建前端项目
```bash
# 在项目根目录 MyAgent/ 下运行
cd frontend
npm create @quick-start/electron . -- --template react-ts
```

### 2. 安装前端依赖
```bash
cd frontend
npm install
```

### 3. 开发模式运行
```bash
# 前端（另开一个终端）
cd frontend
npm run dev
```

```bash
# 后端（激活虚拟环境后）
python backend/api.py
```

## 六、数据存储位置

### 开发环境
- 数据目录：`MyAgent/data/`
- 配置文件：`MyAgent/.env`

### 打包后（标准位置）
- 数据目录：`C:\Users\<用户名>\AppData\Roaming\MyAgent\data\`
- 配置文件：`C:\Users\<用户名>\AppData\Roaming\MyAgent\.env`

## 七、打包

### 1. 打包前端（Electron → exe）
```bash
cd frontend
npm run build:win
```

**输出位置：**
```
frontend/dist/win-unpacked/MyAgent.exe
```

### 2. 打包后端（Python → exe）

**第一步：激活虚拟环境**
```bash
.venv\Scripts\Activate.ps1
```

**第二步：执行打包命令**
```bash
pyinstaller --onefile --name MyAgentServer --distpath backend/dist backend/api.py
```

**输出位置：**
```
backend/dist/MyAgentServer.exe
```

---

## 八、打包后使用

### 1. 启动后端
双击 `MyAgentServer.exe`

### 2. 启动前端
双击 `MyAgent.exe`

### 3. 首次登录
- 用户名：随便填
- 密码：随便填
- API Key：填你的 DeepSeek API Key（会自动保存）

## 九、常见问题

### Q: 打包后后端启动报错找不到 .env？
A: 登录页面输入 API Key 后会自动创建 .env 文件，不用手动创建。

### Q: 前端连接后端失败？
A: 确保后端 exe 已经启动，并且端口 8000 没有被占用。

### Q: 数据存在哪里？
A: 打包后在 `C:\Users\<用户名>\AppData\Roaming\MyAgent\` 目录下。
