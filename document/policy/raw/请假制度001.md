# 员工请假管理制度

## 1. 目的
为规范公司员工请假管理，保障员工依法享有休息休假的合法权益，维护公司正常的生产经营秩序和工作纪律，明确各类假期的申请条件、审批流程和薪资待遇标准，做到有章可循、公平公正，特制定本制度。本制度旨在平衡公司业务发展需要与员工个人权益，确保请假流程高效透明，既保障员工在生病、家庭变故等特殊情况下能及时得到休息和帮助，又避免因人员随意缺勤影响团队协作和项目进度，最终实现公司与员工的共同发展。

## 2. 适用范围
本制度适用于公司全体在职人员，包括：
- 与公司签订正式劳动合同的全职员工
- 处于试用期的员工
- 公司聘请的实习生、兼职人员
- 公司派驻到客户现场或异地办公的员工
- 劳务派遣员工

集团下属各子公司、分公司可参照本制度，结合当地劳动法规制定实施细则，但不得低于本制度规定的标准。

## 3. 假别分类

### 3.1 事假
- 员工请事假需提前3个工作日向部门主管申请
- 事假期间不计发工资
- 全年事假累计不得超过15天
- 单次事假超过5天需总经理审批

### 3.2 病假
- 员工请病假需提供二级以上医院开具的证明
- 病假工资按基本工资的80%发放
- 急诊可事后3个工作日内补交证明
- 全年病假累计超过30天，按医疗期规定处理

### 3.3 年假
- 入职满1年享有5天年假
- 入职满10年享有10天年假
- 入职满20年享有15天年假
- 年假需提前1周申请，可分多次休，当年未休完可顺延1年

### 3.4 婚假
- 员工结婚享有3天婚假
- 晚婚（男25岁/女23岁以上）增加7天，共10天
- 婚假需提供结婚证，一次性休完

### 3.5 产假/陪产假
- 女员工产假98天，其中产前可休15天
- 难产增加15天，多胞胎每多一胎增加15天
- 男员工陪产假15天
- 产假期间按生育保险规定发放津贴

### 3.6 丧假
- 直系亲属（父母、配偶、子女）去世，享有3天丧假
- 祖父母、外祖父母去世，享有1天丧假
- 需赴外地料理丧事的，根据路程远近给予路程假

### 3.7 调休
- 员工加班后可申请调休
- 平时加班按1:1调休，周末加班按1:2调休
- 调休需在3个月内使用，逾期作废

## 4. 审批权限

| 假别 | 天数 | 审批人 |
|------|------|--------|
| 事假 | 1天以内 | 部门主管 |
| 事假 | 1-3天 | 部门经理 |
| 事假 | 3天以上 | 总经理 |
| 病假 | 全部 | 部门主管 + 人事备案 |
| 年假 | 全部 | 部门主管 |
| 婚假/产假 | 全部 | 总经理 + 人事备案 |

## 5. 请假流程

1. 员工在OA系统提交请假申请，填写假别、时间、事由
2. 按照审批权限逐级审批
3. 人事部门备案存档
4. 审批通过后休假
5. 返岗后及时销假

## 6. 紧急请假
- 突发疾病或紧急情况不能提前申请的，需在当天上班后1小时内电话告知部门主管
- 返岗后1个工作日内补办请假手续

## 7. 违规处理
- 未请假擅自休假按旷工处理
- 旷工1天扣3天工资
- 全年旷工累计3天以上，公司有权解除劳动合同
- 弄虚作假骗取假期，一经发现按旷工处理

## 8. 附则
- 本制度由人事部负责解释
- 本制度自发布之日起执行
- 如有未尽事宜，参照国家相关法律法规执行
